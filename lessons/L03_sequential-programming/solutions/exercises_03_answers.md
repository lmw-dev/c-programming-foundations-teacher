## 🎯 一、 除法与取模速算标准答案（PPT 第4页）

1. `5 / 2` $\rightarrow$ **`2`**（整除天条，丢弃小数位）
2. `5.0 / 2` $\rightarrow$ **`2.5`**（一侧为浮点，自动提升为浮点除法）
3. `5 % 3` $\rightarrow$ **`2`**（正数取余）
4. `-5 % 3` $\rightarrow$ **`-2`**（模号天条：余数符号与被除数 `-5` 一致）
5. `5 % -3` $\rightarrow$ **`2`**（模号天条：余数符号与被除数 `5` 一致）
6. `-5 % -3` $\rightarrow$ **`-2`**（模号天条：余数符号与被除数 `-5` 一致）
7. `12.5 % 3` $\rightarrow$ **编译报错**（取模天条：`%` 两侧必须为纯整数，严禁浮点数）

## 🧠 二、 内存推演标准答案（PPT 第6、8页）

### 题目 1：自增动作
- `j = ++i;` $\rightarrow$ `i = 4, j = 4`（前置自增：先自加 1，再将新值赋给 j）
- `j = i++;` $\rightarrow$ `i = 4, j = 3`（后置自增：先将当前值 3 赋给 j，i 再自加 1）

### 题目 2：短路求值分析
- `a = 1`（`a++` 后置自增，执行完表达式后 a 变为 1）
- `b = 1`（由于参与逻辑与 `&&` 时 `a` 的当前初始值为 0 代表假，触发**逻辑与短路**，右侧 `b = 3` 被彻底忽略跳过，故 b 依然保持初始值 1）
- `c = 0`（整条逻辑与表达式判定为假，赋值为 0）

## 📝 三、 离堂小测标准答案（PPT 第18页）

### Q1. 自增后置
- **正确答案**：**B (`y = 8, i = 6`)**
- **解析**：`i++` 后置自增在表达式中先以原值 `5` 参与加法运算：`5 + 3 = 8`，随后 `i` 自加 1 变成 `6`。

### Q2. 表达式求值
- **正确答案**：**A 和 C (`5 / 2` 与 `5 % -3`)**
- **解析**：
  - A: `5 / 2` 整除得 `2`；
  - B: `5.0 / 2` 得浮点数 `2.5`；
  - C: `5 % -3` 符号看被除数，得 `2`；
  - D: `-5 % 3` 符号看被除数，得 `-2`。

### Q3. 逻辑短路简答
- **标准答案**：执行后 `b` 的值依然为 **`2`**。
- **原理解析**：`(a = b)` 将 2 赋值给 a，该子表达式的值为 2（非 0 代表真）。在**逻辑或 `||`** 运算中，只要左侧为真，整条逻辑表达式必然为真，触发**逻辑或短路**，右侧的 `(b = 5)` 根本不会被执行，因此 `b` 依然保持原来的值 2。
