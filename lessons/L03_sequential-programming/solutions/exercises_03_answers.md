## 🎯 一、 天条速算标准答案（PPT 第4页）

1. `5 / 2` $\rightarrow$ **`2`**（整数除整数，整除天条舍弃小数）；
2. `5.0 / 2` $\rightarrow$ **`2.5`**（一侧为浮点数，执行双精度实数除法）；
3. `5 % 3` $\rightarrow$ **`2`**（取模余数为 2）；
4. `-5 % 3` $\rightarrow$ **`-2`**（取模符号天条：结果符号只看被除数/前操作数）；
5. `5 % -3` $\rightarrow$ **`2`**（被除数为正数 5，结果为正数 2）；
6. `-5 % -3` $\rightarrow$ **`-2`**（被除数为负数 -5，结果为负数 -2）；
7. `12.3 % 3` $\rightarrow$ **编译报错**（取模天条：`%` 两侧操作数必须全部为整数）。

## 🧠 二、 内存推演与复合赋值标准答案（PPT 第6、8、13页）

### 题目 1：自增自减
- `j = ++i;` $\rightarrow$ `i = 4`, `j = 4`（前置自增：先自加为 4，再传给 j）。
- `j = i++;` $\rightarrow$ `i = 4`, `j = 3`（后置自增：先将当前值 3 传给 j，i 再自加为 4）。

### 题目 2：逻辑短路电路模拟
- `a = 1`, `b = 1`, `c = 0`。
- **原理解析**：`a++` 为后置自增，先取当前值 `0`（代表假）参与逻辑与 `&&` 运算。触发**逻辑与短路**，右侧 `(b = 3)` 被系统直接掐断不执行，因此 `b` 依然保持初始值 `1`。整条表达式最终为假（`c = 0`），随后 `a` 完成后置自增变为 `1`。

### 题目 3：复合赋值隐形括号
- **标准答案**：`x = 0`。
- **原理解析**：`x %= y + 3` 等价于 `x = x % (y + 3)`，即 `10 % (2 + 3) = 10 % 5 = 0`。绝不能拆成 `x = x % y + 3`！

## 📝 四、 离堂小测标准答案（PPT 第28页）

### Q1. 选择题
- **正确答案**：**B (`y = 8`, `i = 6`)**
- **解析**：`i++` 先用后加，参与运算时 `i` 为 `5`，`y = 5 + 3 = 8`；计算完毕后 `i` 自加 1 变为 `6`。

### Q2. 多选题
- **正确答案**：**A (`5 / 2`) 和 C (`5 % -3`)**
- **解析**：
  - A. `5 / 2` 整除结果为 `2`；
  - B. `5.0 / 2` 浮点除结果为 `2.5`；
  - C. `5 % -3` 被除数为正数 5，结果为 `2`；
  - D. `-5 % 3` 被除数为负数 -5，结果为 `-2`。

### Q3. 简答题
- **标准答案**：执行后 `b` 的值为 **`2`**。
- **原理解析**：`(a = b)` 是赋值表达式，将 `2` 赋给 `a`，该表达式的值为 `2`（非 0，代表真）。在逻辑或 `||` 运算中，左侧为真即触发**逻辑或短路**，右侧表达式 `(b = 5)` 被完全忽略不执行，因此 `b` 依然保持初始值 `2`。
