## 🔍 第二部分：程序阅读写输出参考答案

### 读程序 1
- **输出结果**：`a=1, b=2, c=4`
- **解析**：`++a` 先自增使 `a=1` (真)，触发 `||` 短路机制，右侧 `++b` 被阻断不执行，`b` 保持为 2；进入 `if` 体执行 `c += a` 即 `3 + 1 = 4`。

### 读程序 2
- **输出结果**：`3 5 10`
- **解析**：
  1. 第一次调用 `test()`：`static val` 初始化为 1，`val += 2` 变为 3，打印 `3 `；
  2. 第二次调用 `test()`：跳过初始化语句，继承历史残值 3，`val += 2` 变为 5，打印 `5 `；
  3. 回到 `main()`：打印全局变量 `val`，值为 10。

### 读程序 3
- **输出结果**：`20, 40`
- **解析**：`p = arr + 1` 指向 `arr[1]` (20)；`*p` 取出 20；`*(p + 2)` 即 `arr[3]` 取出 40。

## 🛠️ 第三部分：代码纠错与排雷参考答案

1. **结构体排序张冠李戴漏洞**：
   - **分析**：只交换 `score` 分数字段，会导致学生姓名与成绩发生错配错位。
   - **修复**：声明同类型结构体临时变量 `struct Student temp = students[j]; students[j] = students[j+1]; students[j+1] = temp;` 进行整包置换。
2. **文件打开未做 NULL 检查**：
   - **分析**：若 `data.txt` 不存在，`fopen` 返回 `NULL`，直接 `fgets` 将导致空指针崩溃闪退。
   - **修复**：增加 `if (fp == NULL) { perror("打开失败"); return; }`，并在读取完毕后调用 `fclose(fp);`。
