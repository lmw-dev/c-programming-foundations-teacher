## 📝 第一部分：单项选择题（10题，每题2分，共20分）

1. 在 C 语言中，下列合法的八进制整型常量是：
   - **A.** `018`
   - **B.** `0x12`
   - **C.** `012`
   - **D.** `128`

2. 若有定义 `short a = 32767; a = a + 1;`，在 16 位补码系统中，`a` 的值最终为：
   - **A.** `32768`
   - **B.** `-32768`
   - **C.** `0`
   - **D.** `-1`

3. 执行语句 `int i = 1, j = 1, k = 1; int res = (i++ || ++j) && ++k;` 后，`i, j, k` 的值分别为：
   - **A.** `2, 1, 2`
   - **B.** `2, 2, 2`
   - **C.** `1, 1, 1`
   - **D.** `2, 2, 1`

4. 关于 `switch(expr)` 语句，下列说法正确的是：
   - **A.** `expr` 可以是 `float` 或 `double` 类型
   - **B.** `case` 标签后可以是变量表达式（如 `case x+y:`）
   - **C.** 若缺少 `break;` 语句，程序将从匹配的 case 开始一直向下穿透执行
   - **D.** `default` 子句必须写在所有 `case` 的最前面

5. 已知 `int a[2][3] = {1, 2, 3, 4, 5, 6};`，下列关于二维数组在内存中存储方式的描述正确的是：
   - **A.** 按列优先网格存储
   - **B.** 按行优先（Row-Major）连续线性平铺存储
   - **C.** 各行存储在完全不连续的离散内存碎片中
   - **D.** 声明时第二维（列数）可以随意省略

6. 已知 `int a[3] = {10, 20, 30}, *p = a;`，执行 `y = *p++;` 之后，`y` 的值和 `*p` 的值分别为：
   - **A.** `y = 10, *p = 20`
   - **B.** `y = 20, *p = 20`
   - **C.** `y = 10, *p = 10`
   - **D.** `y = 11, *p = 20`

7. 字符数组 `char sa[] = "Hi";` 与字符指针 `char *sp = "Hi";` 的本质区别在于：
   - **A.** `sa` 分配在栈区可修改，`sp` 指向只读常量区不可修改
   - **B.** `sa` 占 2 字节，`sp` 占 3 字节
   - **C.** `sp` 可以修改字符串第一个字符，`sa` 不能修改
   - **D.** 两者在物理存储和可修改性上没有任何区别

8. 在函数内部定义的 `static int count = 0;`，其核心物理特征是：
   - **A.** 每次调用该函数时都会重新初始化为 0
   - **B.** 分配在静态存储区，函数退出栈帧销毁后依然存活，且初始化仅执行 1 次
   - **C.** 可以在其他文件中通过 `extern` 直接访问
   - **D.** 变量会在函数结束时被操作系统强制销毁

9. 关于结构体（`struct`）与共用体（`union`）的内存占用，下列说法正确的是：
   - **A.** 结构体各成员共享同一内存首地址
   - **B.** 共用体占用的总内存大小等于其最大成员所占的字节数
   - **C.** 结构体变量之间不能使用等号直接赋值
   - **D.** 共用体所有成员可以同时独立保存各自的数据

10. 带参宏 `#define SQUARE(x) x * x`，计算 `SQUARE(2 + 3)` 的结果是：
    - **A.** `25`
    - **B.** `11`
    - **C.** `10`
    - **D.** 编译报错
