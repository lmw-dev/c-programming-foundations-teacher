## ⚠️ 二、 经典翻车点改错答案（PPT 第12页）

### 案例 1：连等声明
- **错误原因**：在声明语句中，`b` 和 `c` 尚未被分配类型与内存空间，不能直接作为左值赋初值。
- **正确改法**：
  ```c
  int a, b, c;
  a = b = c = 3;  // 先声明后赋值
  ```

### 案例 2：同名地雷
- **错误原因**：在同一个作用域/代码块中，不能重复定义同名变量。
- **正确改法**：重命名其中一个变量，如 `int score_int = 90; float score_float = 95.5f;`。

### 案例 3：未声明先使用
- **错误原因**：违背了 C 语言**“先声明，后使用”**的原则。编译器无法预先划定该变量的内存字节长度与存储格式。
- **正确改法**：使用前必须声明其类型，如 `int x = 10;`。

## 🔍 三、 整型溢出与补码运算深度剖析答案（PPT 第15页）

1. **溢出原因**：16 位有符号整型 `int` 的取值范围为 `-32768 ~ +32767`。`20000 + 20000 = 40000` 超出最大值上限发生整型溢出，二进制补码最高位（符号位）溢出变成 `1`，被计算机解释为负数 `-25536`。
2. **正确改法**：
   - 方式 1（强制类型转换）：`c = (long long)a + b;`，将运算提升为 64 位宽；
   - 方式 2（声明高规格类型）：直接将变量声明为 `long long a = 20000LL, b = 20000LL;`。

## 💡 四、 概念辨析答案（PPT 第17页）

- **字符 `'B'`**：占 **1 字节**。存储的是 `'B'` 的 ASCII 码值 `66`。
- **字符串 `"B"`**：占 **2 字节**。系统会在字符 `'B'` 后面自动追加一个不可见的字符串结束符 `'\0'`（ASCII 值为 0），即物理存储为 `['B', '\0']`。

## 📝 五、 离堂小测标准答案（PPT 第24页）

### 1. 选择题
- **正确答案**：**B (`a12`, `_temp`, `student_name`)**
- **解析**：
  - A 选项中 `int` 是关键字；
  - C 选项中 `2_play` 以数字开头，`book$` 包含非法字符 `$`。

### 2. 简答题
- **标准答案**：字符 `'B'` 占 1 字节；字符串 `"B"` 占 2 字节（含末尾隐式 `'\0'`）。

### 3. 简答题
- **标准答案**：局部变量未初始化时，其内存中存放的是上一个程序使用后残留的随机数据（称为“幽灵垃圾值”）。直接读取或用于运算将导致不可预期的逻辑错误与安全漏洞。
