## 🎯 一、 正误找茬大作战标准答案（PPT 第6、7、13、14页）

1. `void process(int matrix[][], int n);`
   - **合法性**：**非法**
   - **原因**：C 语言要求二维数组形参的第二维（列数）绝对不能省略，必须写为 `int matrix[][列数]`。
2. `#define PI 3.14159;`
   - **潜在风险**：预处理是纯文本替换，若在代码中写 `double s = PI * r * r;` 会被展开为 `double s = 3.14159; * r * r;`，引发语法编译错误。
3. `#define MULTIPLY(x, y) x * y`
   - **计算结果**：`25`
   - **原因**：`10 / MULTIPLY(2, 5)` 被文本展开为 `10 / 2 * 5`，根据左结合性先算 $10 / 2 = 5$，再算 $5 \times 5 = 25$（严重偏离预期 $10 / (2 \times 5) = 1$）。

## 🧠 二、 static 静态变量打表追踪 Trace Table（PPT 第12页）

| 循环轮次 `i` | 传入实参 `a` | 局部变量 `b`（栈区） | 静态变量 `c`（静态区） | 函数返回值 `a+b+c` |
|:---:|:---:|:---:|:---:|:---:|
| 第 1 次 (`i=1`) | 1 | 1 | **4** (3+1) | **6** (1+1+4) |
| 第 2 次 (`i=2`) | 2 | 1 (重新初始化为0) | **5** (4+1，跳过初始化) | **8** (2+1+5) |
| 第 3 次 (`i=3`) | 3 | 1 (重新初始化为0) | **6** (5+1，跳过初始化) | **10** (3+1+6) |

- **控制台最终输出**：`6 8 10`

## ⚔️ 三、 分步纯文本宏替换推演（PPT 第15页）

1. `D(3)` 计算：
   - **纯文本展开式**：`3 * 3 - 2`
   - **最终计算值**：`7`
2. `D(D(3))` 计算（北石化经典真题）：
   - **纯文本无脑展开式**：`3 * 3 - 2 * 3 * 3 - 2 - 2`
   - **计算过程**：$9 - 18 - 2 - 2 = -13$
   - **最终计算值**：`-13`

## 📝 四、 离堂小测标准答案（PPT 第20页）

### Q1. 数组作为函数实参传递的本质
- **正确答案**：**B**
- **解析**：数组名作实参时自动退化为指针常量，传递的是首元素的物理内存地址（8 字节指针值）。

### Q2. 形参二维数组规格天条
- **正确答案**：**C**
- **解析**：二维数组作形参，第一维行数可省略，第二维列数绝对不能省略；`a[3][]` 属于非法声明。

### Q3. 带参宏的黄金防错规范
- **正确答案**：**D (`#define S(a, b) ((a) * (b))`)**
- **解析**：每个形参用圆括号保护，表达式整体也用圆括号保护，实现双重防护。
