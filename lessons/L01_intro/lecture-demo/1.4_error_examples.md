## 🚨 常见编译错误案例与现象剖析

### 案例 1：遗漏英文分号 `;`
- **错误代码**：
  ```c
  #include <stdio.h>
  int main(void) {
      printf("Hello World")   // 🚨 错误：末尾漏写英文分号
      return 0;
  }
  ```
- **报错提示**：`error: expected ';' before 'return'`（MSVC: `C2143: 语法错误: 缺少 ";" 在 "return" 的前面`）
- **原因剖析**：C语言中分号 `;` 是语句的法定终结符，回车换行无法代替分号。
- **修正方法**：在 `printf(...)` 语句末尾补齐英文半角分号 `;`。

---

### 案例 2：混用中文标点符号（如中文分号 `；` 或双引号 `“”`）
- **错误代码**：
  ```c
  #include <stdio.h>
  int main(void) {
      printf("这是中文分号！")；  // 🚨 错误：使用了中文全角分号
      return 0;
  }
  ```
- **报错提示**：`error: stray '\357' in program` 或 `C2018: 未知字符 '0xa3'`
- **原因剖析**：C 语言编译器仅能识别 ASCII 码英文半角字符，中文全角标点在源码中会被识别为非法外来乱码。
- **修正方法**：务必切换为英文半角输入法，将 `；` 改为 `;`，将 `“”` 改为 `""`。

---

### 案例 3：主函数名字拼写错误（`main` 误写为 `mian`）
- **错误代码**：
  ```c
  #include <stdio.h>
  int mian(void) {             // 🚨 错误：main 拼写成 mian
      printf("入口拼错了！\n");
      return 0;
  }
  ```
- **报错提示**：`undefined reference to 'main'` 或 MSVC 链接器 `LNK2019: 无法解析的外部符号 _main`
- **原因剖析**：C 语言严格区分大小写且必须由唯一的 `main` 函数充当执行起点入口。拼写错误会导致编译器找不到程序入口。
- **修正方法**：将 `mian` 纠正拼写为 `main`。

---

### 案例 4：转义字符反斜杠写反（`/n` 误写为普通字符）
- **错误代码**：
  ```c
  #include <stdio.h>
  int main(void) {
      printf("第一段/n第二段\n"); // 🚨 逻辑现象：/n 原样输出，未换行
      return 0;
  }
  ```
- **运行现象**：编译不报错，但屏幕上原样打印出了 `第一段/n第二段`，未能实现换行。
- **原因剖析**：反斜杠 `\`（向后倒）才是转义引导符，正斜杠 `/` 只是普通的数学除号字符。
- **修正方法**：将 `/n` 修改为 `\n`。

---

### 案例 5：双引号未闭合或跨行断裂
- **错误代码**：
  ```c
  #include <stdio.h>
  int main(void) {
      printf("字符串未闭合);   // 🚨 错误：双引号只有前半边
      return 0;
  }
  ```
- **报错提示**：`error: missing terminating '"' character` 或 `C2001: 常量中有换行符`
- **修正方法**：字符串必须由成对的英文半角双引号 `""` 包裹。
