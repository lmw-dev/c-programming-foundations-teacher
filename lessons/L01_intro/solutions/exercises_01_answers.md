## 🎯 一、 快速判断（对应 PPT 第8页 & 第17页）

### 题目 1 答案：**B**

#### 深度考点解析：
- **正确项 B (`\n`)**：反斜杠 `\` 是 C 语言中法定的**转义字符引导符**。`\n`（Newline）会指示控制台光标移动到下一行的行首。
- **错误项 A (`/n`)**：正斜杠 `/` 只是普通的 ASCII 数学除号字符，写入字符串会直接原样打印出 `/n`，无法实现换行。
- **错误项 C (`n`)**：普通字母。
- **错误项 D (`//n`)**：字符串内不会被识别为单行注释，而是原样打印 `//n`。

## ⚔️ 二、 编程改错题（对应 PPT 第18页【找茬大作战】）

### 题目 2：[`exercise_fix_errors.c`](../exercises/exercise_fix_errors.c) 改错答案

#### 3 处语法地雷定位与修复：
1. **地雷 1**：主函数名拼写错误（`int mian(void)` $\rightarrow$ 必须修正为 `int main(void)`）。
2. **地雷 2**：语句漏写分号或混用中文分号（`printf("Hello, C Programming!\n")` 末尾必须补齐英文半角分号 `;`）。
3. **地雷 3**：转义换行符斜杠方向写反（`printf("Welcome to our class!/n")` $\rightarrow$ 必须将 `/n` 修正为 `\n`）。

#### 修复后的标准完整源码：
```c
#include <stdio.h>

int main(void)
{
    printf("Hello, C Programming!\n");
    printf("Welcome to our class!\n");

    return 0;
}
```

## 📝 三、 离堂小测答案与讲评指引（对应 PPT 第25页）

### Q1 答案：**B**
- **考点解析**：C 语言标准规定，每一个独立构建的可执行 C 程序中，**`main` 函数有且仅有一个**，它是操作系统调用该程序时的唯一入口大门。

### Q2 答案：**C**
- **考点解析**：`printf("Hello\nWorld");` 中间的 `\n` 触发换行，精准实现第一行输出 `Hello`、第二行输出 `World`。

### Q3 答案要点：
- **所属错误类别**：**逻辑错误（Logical Error） / 语义错误**。
- **排查与解决手段**：
  1. 编译器只负责校验词法与句法规范，无法探知开发者的真实算法意图；
  2. 必须依靠**人工单步调试（Debug）**、**设置断点（Breakpoint）**、**单步步过/单步步入（F10/F11）**、观察变量监视窗口中的数据流变化，逐步缩小问题范围并纠正算法公式。
