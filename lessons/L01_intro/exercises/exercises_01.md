## 👥 三、 同伴互评 Code Review 标准卡（对应 PPT 第24页）

与同桌交换电脑屏幕，按以下 **Review 互评三步走** 进行交叉审核：

1. **读得通**：看着对方的代码，能否不用运行就在脑海中准确模拟出控制台输出的排版样式？
2. **找隐患**：
   - 源代码文件后缀是否为 `.c`（非 `.cpp` 或 `.txt`）？
   - 语句末尾是否全是英文半角分号 `;`？
   - 双引号中的反斜杠 `\n` 方向是否正确？
   - 个人名卡右侧星号边框是否垂直对齐？
3. **点个赞**：夸奖对方一个写得精妙、排版工整或富有创意的细节。

### Q2【单选·期末高频真题】：源程序基本单位
下列关于 C 语言源程序基本构成的叙述中，正确的是（    ）。
- **A.** C 程序由语句构成，语句是程序的基本组成单位
- **B.** C 程序由函数构成，函数是程序的基本组成单位
- **C.** C 程序由过程构成，过程是程序的基本组成单位
- **D.** C 程序由子程序构成，主程序和子程序组成完整系统

### Q3【单选·期末高频真题】：关于 `main` 函数的位置与执行
在一个 C 语言源程序中，关于 `main` 函数的位置与执行，下列说法正确的是（    ）。
- **A.** 必须放在源程序的最开头
- **B.** 必须放在源程序的最末尾
- **C.** 可以放在源程序的任意位置，但程序总是从 `main` 函数开始执行
- **D.** 可以放在任意位置，且程序总是从源文件第一行顺序执行

### Q4【排雷思考】：关于语法错误 vs 逻辑错误
