## 🎯 一、 代码诊所大排查标准答案（PPT 第6、7、16页）

1. `int add(int x, int y); { return x + y; }`
   - **错误原因**：函数定义首部的参数括号后多写了分号 `;`，导致编译器误判函数已结束，使后面的 `{}` 成为孤立代码块。
   - **修改方案**：删去首部末尾的分号，改为 `int add(int x, int y) { ... }`。
2. `int square(x) { return x * x; }`
   - **错误原因**：C 语言函数形参列表中，每个形参都必须明确声明类型。
   - **修改方案**：补全形参类型 `int square(int x) { ... }`。
3. `int check_level(int score) { if (score >= 60) return 1; }`
   - **潜在风险**：当 `score < 60` 时，函数没有执行任何 `return` 语句，直接退出将向主调函数返回随机未定义的内存垃圾值。
   - **修改方案**：补齐 `else return 0;`。

## 🧠 二、 内存栈帧与单向值传递追踪（PPT 第9、10、11页）

### 题目 1：形参实参数据隔离
- **输出结果**：`a = 10`
- **核心原因**：形参 `x` 和实参 `a` 位于不同的物理栈帧中。调用时仅进行了单向值复制（`x = 10`），函数内部修改 `x = 99` 仅改变了临时形参 `x` 的栈单元，函数返回时 `x` 被销毁，外部实参 `a` 毫发无损。

### 题目 2：返回值强制类型截断
- **返回值**：`12`
- **原因**：函数类型拥有最高统治权。虽然内部计算为浮点数 `12.56636`，但由于函数首部声明为 `int`，返回时系统强行截断小数部分，仅保留整数 `12`。

## ⏱️ 三、 static 静态局部变量输出预测（PPT 第14页）

- **连续 3 次调用输出**：`a=2, b=2 | a=2, b=3 | a=2, b=4 |`
- **解析**：
  - `a` 是普通局部变量（栈区），每次调用重新初始化为 1，加 1 后为 2，退出销毁；
  - `b` 是静态局部变量（静态存储区），仅在首次调用时初始化为 1，后续调用跳过初始化，在原有值基础上累加（$1 \to 2 \to 3 \to 4$）。

## 📝 四、 离堂小测标准答案（PPT 第20页）

### Q1. 函数原型声明规范
- **正确答案**：**C**
- **解析**：原型声明是完整 C 语句，末尾必须加分号；若函数定义在调用处之后，必须做声明。

### Q2. 局部变量与全局变量同名
- **正确答案**：**B**
- **解析**：局部变量与全局变量同名时，在局部作用域内局部优先，全局变量被完全遮蔽。

### Q3. static 静态局部变量的生存期
- **正确答案**：**C**
- **解析**：`static` 局部变量分配在静态数据区，生命期与全局变量一致（贯穿程序整个运行过程），直到程序退出才释放。
