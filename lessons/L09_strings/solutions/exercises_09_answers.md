## 🎯 一、 正误找茬大作战标准答案（PPT 第6、7、12页）

1. `char c = "A";`
   - **合法性**：**非法 / 严重类型不匹配**
   - **原因**：`"A"` 是字符串常量（本质是 `const char*` 指针地址，占 2 字节），不能赋值给单个字符变量 `char`。
2. `char s1[20] = "China", s2[20]; s2 = s1;`
   - **合法性**：**非法**
   - **原因**：数组名 `s2` 是只读的地址常量，不能作为左值被赋值；必须调用 `strcpy(s2, s1)`。
3. `if (s1 == "China") { printf("Match!\n"); }`
   - **逻辑正确性**：**错误**
   - **原因**：`==` 比较的是两个字符串在内存中的起始物理地址，而非字符内容；必须使用 `strcmp(s1, "China") == 0`。
4. `char s[5] = "China"; printf("%s\n", s);`
   - **潜在运行风险**：**乱码（烫烫烫）或崩溃**
   - **原因**：`s` 只有 5 字节，刚排放下 5 个字母，无法容纳末尾的 `'\0'` 结束标志；`printf("%s")` 越界扫描相邻栈内存引发乱码。

## 🧠 二、 strlen (数货) vs sizeof (量盒子) 终极打表（PPT 第13页）

| 变量定义语句 | `sizeof(var)` 返回值（字节） | `strlen(var)` 返回值（字符数） | 关键考点说明 |
|:---|:---:|:---:|:---|
| `char a[] = "Hello";` | **6** | **5** | 双引号隐式追加 `'\0'` |
| `char b[10] = "Hello";` | **10** | **5** | 盒子大小为 10，装了 5 个有效货 |
| `char c[] = {'H','e','l','l','o'};` | **5** | **危险/不确定** | 无 `'\0'` 哨兵，strlen 顺着内存狂奔 |
| `char d[10] = {'H','i','\0','A','B'};` | **10** | **2** | 提前遇到 `'\0'` 立即踩死刹车 |

## ⚔️ 三、 标准库函数行为预测（PPT 第14、15、16页）

1. `strcat(s1, s2)` 执行后：
   - `s1` 内容为 `"SuperStar"`
   - `strlen(s1)` 长度为 **9**（5 + 4）
2. `strcmp("App", "Apple")` 的正负性：
   - 返回 **负数 (< 0)**
   - 原因：前三个字母相同，`"App"` 遇到 `'\0'`（ASCII=0），而 `"Apple"` 对应位置为 `'l'`（ASCII=108），$0 < 108$ 判定 `"App"` 更小。

## 📝 四、 离堂小测标准答案（PPT 第20页）

### Q1. 字符数组物理内存占用
- **正确答案**：**C (5 和 10)**
- **解析**：`strlen(s)` 数出有效字符数 5；`sizeof(s)` 量出整个盒子总物理空间 10 字节。

### Q2. 字符串内容相等判定
- **正确答案**：**B**
- **解析**：在 C 语言中，数组名和字符串常量均代表物理内存地址，`==` 比较的是地址门牌号而非字符串内容。

### Q3. 安全整行输入函数
- **正确答案**：**C (`fgets(str, sizeof(str), stdin)`)**
- **解析**：`gets()` 因无边界检查已被现代标准废弃；`fgets` 强制要求传入最大接收字节，具备工业级防御性。
