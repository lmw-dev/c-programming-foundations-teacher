## 🎯 一、 优先级对决标准答案（PPT 第8页）

已知 `int a = 3, b = 4, c = 5;`：

1. `a + b > c && b == c` $\rightarrow$ **`0` (假)**
   - 步骤：`a + b = 7`，`7 > 5` 为真(1)；`4 == 5` 为假(0)；`1 && 0` 得 `0`。
2. `a || b + c && b - c` $\rightarrow$ **`1` (真)**
   - 步骤：`b + c = 9`，`b - c = -1`。由于 `&&` 优先级高于 `||`，先算 `9 && -1` 得 `1`（非0即为真！）；再算 `3 || 1`，得 `1`。
3. `!(a > b) || !c` $\rightarrow$ **`1` (真)**
   - 步骤：`a > b` (3 > 4) 为假(0)，`!(0)` 得 `1`。进入 `||` 时左侧为 1 触发**短路**，整条表达式结果直接为 `1`。
4. `a = 0 || b > 2` $\rightarrow$ 表达式结果为 **`1`**，变量 `a` 最终值为 **`1`**
   - 步骤：赋值运算符 `=` 优先级最低。右侧 `b > 2` (4 > 2) 为真(1)，`0 || 1` 得 `1`，最后执行 `a = 1`。

## 🧠 二、 内存与语法推演标准答案（PPT 第11、14页）

### 题目 1：迷失的 else
- **配对结果**：根据 C 语言就近配对铁律（无视缩进），`else` 紧紧与它上面最近且未配对的 **`if (b > 0)`** 配对。
- **输出结果**：**什么都不输出**。因为最外层 `if (a > 0)` 中 `a = -5` 不成立，整个复合语句直接被跳过。

### 题目 2：找茬排雷
- **漏洞分析**：`if (score >= 60);` 后面误加了分号 `;`。在 C 语言中，分号代表一条空语句，导致 `if` 条件成立与否只控制这个空语句；后面的大括号 `{ printf(...); }` 沦为无条件的普通代码块，无论 `score` 是多少分都会打印“考试及格！”。

## 📝 三、 离堂小测标准答案（PPT 第19页）

### Q1. 嵌套配对
- **正确答案**：**B (`BBB`)**
- **解析**：`else` 与 `if (y == 20)` 配对。由于 `x == 5` 成立，进入内层；内层 `y == 20` 不成立，落入对应的 `else` 分支，打印出 `BBB`。

### Q2. 字符区间
- **正确答案**：**B (`ch >= 'A' && ch <= 'Z'`)**
- **解析**：A 选项数学连写在 C 语言中会先算 `'A' <= ch` 得 1，再用 `1 <= 'Z'` 恒为真；C 选项逻辑或表示大于 'A' 或者小于 'Z'（涵盖了所有字符）。

### Q3. 短路求值阐述
- **标准答案**：短路求值是指在求解逻辑表达式时，一旦左侧操作数已经能确定整条表达式的最终真假值，CPU 将立即停止计算右侧剩余的表达式。
- **典型示例**：在 `a && b` 中，若 `a` 判定为假（0），整条逻辑与必然为假，右侧 `b` 不再被执行（例如 `(x == 0) && (y = 5)` 当 x 不为 0 时，y 不会被赋值）。
