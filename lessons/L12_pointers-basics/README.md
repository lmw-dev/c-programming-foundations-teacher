## 🏫 教学实施精细化指引

### 1. 特工 008 寻找保险箱密码的物理映像（PPT 第4页）
```text
       虎跑号寄存箱                      龙井号寄存箱
 ┌──────────────────────┐          ┌──────────────────────┐
 │ 物理地址: 0217       │          │ 物理地址: 1976       │
 ├──────────────────────┤          ├──────────────────────┤
 │ 存放内容: [ 1976 ]   │ ───指向──>│ 存放内容: [  911 ]   │
 └──────────────────────┘          └──────────────────────┘
         (指针变量)                         (目标变量)
```

### 2. 多函数协作修改主调数据的“黄金三步法则”（PPT 第16页）
```text
 ┌────────────────────────────────────────────────────────┐
 │ 【第一步】                                              │
 │ 在主调函数中，将该变量的地址 (&a) 或指向该变量的指针作为实参  │
 └───────────────────────────┬────────────────────────────┘
                             │ 传递
 ┌───────────────────────────▼────────────────────────────┐
 │ 【第二步】                                              │
 │ 在被调函数中，必须使用指针类型的形参 (int *p) 接收该地址    │ 
 └───────────────────────────┬────────────────────────────┘
                             │ 间接访问
 ┌───────────────────────────▼────────────────────────────┐
 │ 【第三步】                                              │
 │ 在被调函数中，必须通过 * 运算符改变形参所指向变量的值 (*p=...) │ 
 └────────────────────────────────────────────────────────┘
```

| 课时 | 时长 | 教学环节 | 核心任务与对应 PPT |
