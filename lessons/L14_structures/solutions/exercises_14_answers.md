## 🎯 一、 代码诊所大排查标准答案（PPT 第4、8、16页）

1. `struct Student { int id; char name[20]; }`
   - **错误原因**：结构体模板定义以分号结束，被视为一条语句，末尾漏写分号 `;`。
   - **修改方案**：大括号后补上分号 `};`。
2. `stu1.name = "张三";`
   - **错误原因**：`stu1.name` 是字符数组名，属于地址常量，不能作为左值进行直接赋值。
   - **修改方案**：使用 `strcpy(stu1.name, "张三");`。
3. `if (stu1 == stu2)`
   - **错误原因**：C 语言不支持两个结构体变量整体进行 `==` 或 `!=` 关系比较。
   - **修改方案**：逐成员比较，如 `if (stu1.id == stu2.id && strcmp(stu1.name, stu2.name) == 0)`。

## 🧠 二、 运算符大对决标准答案（PPT 第11、12、13页）

| 表达式 | 合法性 (合法/非法) | 若合法写出结果，若非法写出原因 |
|:---|:---:|:---|
| `stu.id` | **合法** | 计算结果为 **`101`**（普通变量通过点运算符直接访问） |
| `ptr->id` | **合法** | 计算结果为 **`101`**（结构指针通过箭头指向运算符间接访问） |
| `(*ptr).id` | **合法** | 计算结果为 **`101`**（先解引用还原为变量，再点成员） |
| `*ptr.id` | **非法** | 编译报错！点 `.` 优先级高于 `*`，解析为 `*(ptr.id)`，而指针 `ptr` 没有 `id` 成员 |
| `stu->id` | **非法** | 编译报错！普通变量不能使用指向运算符 `->` |
| `ptr.id` | **非法** | 编译报错！指针变量不能直接使用点运算符 `.` |

## ⚔️ 三、 整包置换 vs 单字段错位辨析标准答案（PPT 第2、17、18页）

1. **引发灾难**：
   - 仅对调了 `sum` 总分数值，而学生学号 `id`、姓名 `name`、各门课成绩依然停留在原地，导致“张三的名字配上李四的成绩”，发生数据张冠李戴的特大数据库错位事故！
2. **正确的整包置换写法**：
   ```c
   struct Student temp = arr[j];
   arr[j] = arr[j + 1];
   arr[j + 1] = temp;
   ```

## 📝 四、 离堂小测标准答案（PPT 第20页）

### Q1. 结构体类型与变量的内存分配
- **正确答案**：**B**
- **解析**：结构体类型的定义只是“画图纸”，不占用任何物理内存；只有在声明具体变量（盖房子）时才在栈区开辟空间。

### Q2. 结构体指针作函数参数的优势
- **正确答案**：**C**
- **解析**：传递指针只需复制 4 或 8 字节的物理内存地址，彻底杜绝在系统栈区大面积全量复制（几百字节）所造成的内存暴涨与性能损耗。

### Q3. 结构体整体赋值机制
- **正确答案**：**B**
- **解析**：同类型的两个结构体变量支持整体赋值（`stu2 = stu1;`），底层执行二进制内存块镜像复制（Block Copy），所有内嵌成员一并完整深拷贝。
