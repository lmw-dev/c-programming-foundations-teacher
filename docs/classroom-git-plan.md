# 渐进式 Git 教学方案

> 本方案面向职业学校专升本学生（通常无 Git 经验），在不影响基础成绩的前提下逐步引入版本控制概念。Git 教学后置，前几讲不作任何 Git 要求。

## 教学阶段

### 阶段一：教师管理代码（第01—04讲）

**学生侧**：不要求使用 Git，不要求注册任何账号。

**教师侧**：
- 教师使用本仓库管理课堂演示代码
- 每讲演示代码通过 USB 或校园网盘分发给学生
- 学生提交作业以 `.c` 源文件为主，通过教学管理系统或 U 盘

**教学融入**：
- 可在第01讲简单提及"代码可以备份和追溯"的概念，但不展开操作

---

### 阶段二：认识仓库与版本概念（第05—08讲）

**学生侧**：
- 教师在课堂上演示 GitHub/Gitee 页面，展示"代码仓库"的概念
- 介绍 commit（提交记录）、branch（分支）、clone（下载）的直观含义
- **不要求学生操作命令行**，不要求学生注册账号

**教师侧**：
- 教师在课堂上演示从仓库获取代码的流程
- 演示如何查看代码的修改历史

**条件依赖**：
- 机房网络可访问 GitHub 或 Gitee（需确认）
- 或使用校内 Git 服务（如 GitLab，需确认）

---

### 阶段三：一次克隆与修改演示（第09—12讲）

**学生侧**：
- 视机房条件，安排一次 Git 动手体验课
- 学生在教师指导下执行一次 clone → 修改 → commit 流程
- **仅限课堂内完成，不作为课后作业要求**

**建议流程**：
```
1. git clone <仓库地址>        # 获取代码
2. 修改一个 .c 文件             # 编辑代码
3. git add <文件名>             # 暂存修改
4. git commit -m "修改说明"     # 提交修改
```

**条件依赖**：
- 机房网络可访问代码仓库平台
- Git 客户端已安装在学生机上
- 学生有账号（或使用统一测试账号）

---

### 阶段四：可选 Git 综合任务（第13—16讲）

**学生侧**：
- 综合任务可选使用 Git 管理代码版本
- **不能作为基础成绩门槛**：不使用 Git 不扣分
- 使用 Git 的学生可获得额外过程性加分（待确认是否适用）

**教师侧**：
- 提供简单的 Git 操作手册（clone/pull/add/commit/push）
- 推荐使用 GUI 工具（如 GitHub Desktop）降低命令行门槛

---

## 实施前必须确认的条件

| 确认项 | 影响范围 | 优先级 | 状态 |
|--------|----------|--------|------|
| 机房网络是否可访问 GitHub/Gitee | 阶段二演示、阶段三实操 | 高 | **待确认** |
| 学生机是否安装 Git 客户端 | 阶段三实操 | 高 | **待确认** |
| 学生账号政策（GitHub/Gitee注册） | 阶段三实操 | 高 | **待确认** |
| 是否允许使用 USB 作为备选分发渠道 | 阶段一教学分发 | 中 | **待确认** |
| 是否允许使用校园网盘作为备选分发渠道 | 阶段一教学分发 | 中 | **待确认** |
| 是否有校内 GitLab 或类似服务 | 阶段二/三 | 中 | **待确认** |
| 教学管理系统是否支持代码提交 | 作业提交 | 中 | **待确认** |
| 学生计算机基础水平 | 教学节奏调整 | 低 | **待确认** |

## 备选分发方案

如果机房网络不支持 Git：

| 方案 | 适用场景 | 优缺点 |
|------|----------|--------|
| USB 分发 | 无网络环境 | 简单可靠；版本管理需教师手动 |
| 校园网盘 | 有内网但无外网 | 支持文件共享；无版本控制功能 |
| 离线安装包 | Git 需要安装 | 一次安装后可本地使用 |

## 注意事项

1. **前4讲绝不涉及 Git 命令行**，以免增加学生认知负担
2. **Git 教学不纳入基础成绩考核**，仅作为拓展能力培养
3. **教师版本控制与学生版本控制分开管理**，不混用
4. 所有 Git 操作演示使用教师账号，学生如需使用应自行注册
5. 不在课堂上要求学生提交 GitHub 个人链接或公开仓库地址
