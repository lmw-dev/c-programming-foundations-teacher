## 课程目标

### 知识目标
1. 掌握C语言基本知识：程序结构、数据类型、运算符、表达式
2. 掌握顺序/选择/循环三类控制结构
3. 掌握数组、函数、指针、结构体和文本文件处理
4. 理解C函数参数均为值传递（传入地址值后通过解引用修改调用者对象）
5. 了解数组名在多数表达式中转换为首元素地址，但不可重新赋值

### 能力目标
1. 阅读和理解简短C程序
2. 根据输入-处理-输出编写程序（累加、计数、查找、最值、统计、排序）
3. 基本编译、调试和错误定位能力
4. 使用结构体数组管理简单记录、使用文本文件完成基础读写

### 素养目标
1. 规范编写程序（缩进、命名、注释）
2. 调试与验证意识（边界检查、数组下标、文件打开）
3. 安全意识（禁用gets、字符串限宽输入、文件打开失败处理）
4. 模块化与完整提交习惯

## 十章知识脉络

```
第1章 C语言概述 → 第2章 数据类型 → 第3章 顺序结构
    → 第4章 选择结构 → 第5章 循环结构
        → 第6章 数组（一维/二维/字符串）
            → 第7章 函数 → 第8章 指针
                → 第9章 结构体 → 第10章 文件
```
