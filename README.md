## 📖 仓库用途与架构

本仓库服务于《C语言程序设计基础》课程（64学时，16讲，每讲4学时）的教师侧全流程教学管理：

- **课堂演示代码 (`lecture-demo/`)**：每讲包含 2~4 个精心设计、深入底层物理内存机制的课堂可运行演示程序。
- **学生起步模板 (`starter/`)**：每讲包含 2~3 个带有清晰 `TODO` 引导的上机实验初始骨架代码。
- **当堂练习与评测 (`exercises/`)**：每讲包含 1 份结构化评测题单（Markdown）+ 1 份高频翻车/改错排雷源码。
- **教师参考答案 (`solutions/`)**：每讲包含实操核心任务标准答案源码 + 评测题单深度解析（教师私有，不向学生公开）。
- **全景导学案 (`README.md`)**：每讲包含本讲知识图谱、PPT 页码映射表、物理机制图解与 4 课时时间分配表。
- **自动化工具链 (`tools/`)**：提供一键全库编译测试脚本 `verify_all.sh` 及深度清理脚本 `clean.sh`。
- **课程全局管理文档 (`docs/`)**：包含 16 讲教学地图 (`lesson-map.md`)、核心案例目录卡 (`case-catalog.md`) 与维护交接文档。

## 🛠️ 运行环境与工具链

### 1. 编译与开发环境兼容性
- **主推荐教学环境**：Visual Studio Community（Windows 版），安装“使用 C++ 的桌面开发”工作负载（内置 MSVC）。
- **跨平台兼容支持**：所有代码严格遵循 C99 / C11 标准，完美兼容 macOS (Clang / GCC)、Linux 及 Dev-C++、VS Code。
- **源码文件规范**：统一使用 `.c` 后缀，蛇形命名法 `snake_case`，UTF-8 字符编码。

### 2. 自动化验证与清理脚本
代码库根目录下提供工程化辅助脚本（位于 `tools/` 目录）：

```bash
# 1. 运行全库 117 个 C 语言教学程序的全量自动化编译与沙箱输入验证
./tools/verify_all.sh

# 2. 一键清理所有构建二进制、调试符号目录及测试产生的临时日志与文本
./tools/clean.sh
```

## 🛡️ 工业级技术规范与教学设计准则

1. **安全输入规范**：禁用不安全的 `gets()`；单词输入使用带限宽格式控制（如 `scanf("%19s", str)`）；整行文本输入统一采用 `fgets()` 并解析去除换行符。
2. **内存机制显性化**：通过打印十六进制物理地址（`%p`）直观呈现栈帧隔离、指针自适应步长、二维数组行优先连续存储以及共用体首地址重叠。
3. **防御性编程铁律**：
   - 指针与动态内存：`malloc` 及 `fopen` 后**必须执行 `NULL` 指针防御检查**；
   - 结构体排序：起泡排序必须执行**整包置换（Block Copy）**，严禁单独交换分数字段以防数据错位；
   - 文件 I/O：操作完毕**必须显式调用 `fclose()`** 触发缓冲区强制冲刷（Flush）落盘。
