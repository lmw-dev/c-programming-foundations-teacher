# C语言程序设计基础 — 教师私有教学代码仓库

> **⚠️ 这是一个教师私有仓库，不对外公开，不包含开源许可证。**

## 仓库用途

本仓库服务于《C语言程序设计基础》课程（64学时，16讲，每讲4学时）的教师侧教学管理：

- **课堂演示代码**：每讲的 `lecture-demo/` 目录存放课堂现场演示的可运行代码
- **学生起步模板**：每讲的 `starter/` 目录存放发给学生的初始代码骨架
- **当堂练习**：每讲的 `exercises/` 目录存放课堂练习题目与说明
- **参考答案**：每讲的 `solutions/` 目录存放教师参考答案（不公开）
- **共享资源**：`shared/` 目录存放通用模板、测试数据和 Visual Studio 配置文件
- **课程文档**：`docs/` 目录存放课程概览、教学地图、案例目录等管理文档

## 运行环境

- **主教学环境**：Visual Studio Community（Windows 版），安装"使用 C++ 的桌面开发"工作负载
- **源文件后缀**：统一使用 `.c`
- **编译器**：MSVC（Visual Studio 内置）
- **机房环境状态**：待学校最终确认

> 其他 IDE（Dev-C++、VS Code 等）仅作兼容性备注，不作为默认教学环境。

## 技术约束

- 字符串输入：禁用独立 `gets`；不含空格的单词使用带宽度限制的 `scanf`（如 `scanf("%31s", buf)`）；整行文本使用 `fgets`
- 函数参数均为值传递；传入地址值后通过指针解引用修改调用者对象
- 数组名在多数表达式中转换为首元素地址，但数组名不可重新赋值
- 文件操作限于文本文件的 `FILE*`、`fopen/fclose`、`fprintf/fscanf`、`fopen` 失败检查
